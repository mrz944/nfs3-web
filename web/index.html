NFS3 Web Runtime

Runs your own copy of Need for Speed III: Hot Pursuit (PC, modern patch) in the browser. Your game folder is copied into this browser's private storage once; nothing is uploaded.

Online play

Race friends in their browsers. Create a room and send them the link.


After Start: Connect Players → Network IPX. One player picks Create Game, everyone else picks the game under Games Available and Join Game. For two players, Peer-to-Peer gives both the same responsiveness.

Click to capture the mouse · Esc releases it
