    How to Race Online

    1. Get the game into this browser. Every player needs their own NFS3 folder (PC, modern patch). Click Choose NFS3 Folder… and pick the folder with nfs3.exe. This happens once; next time it's already here.
    2. Pick a name. Type it under Online Play → Your name. It's what the others see in the room.
    3. Make a room. One player clicks Create Room, gives it a name, and optionally a password and a player limit (2–8). Untick Show in the room list for a private room.
    4. Bring your friends in. Click Copy invite link and send it, or let them pick the room in the Rooms list and click Join. Everyone in the room is listed with their ping and direct or via server.
    5. Everyone clicks Start Game. Wait until all players see the game's menu.
    6. Host the race. The player shown as Best host goes to Connect Players → Network IPX → Create Game. For two players choose Peer-to-Peer, for more Client-Server.
    7. Join the race. The others go to Connect Players → Network IPX, pick the game under Games Available and click Join Game.
    8. Race. The host picks the track and starts. The badge at the top left shows the room and each racer's ping. Click it to copy the invite link.
    Lag
    The host's car reacts instantly; everyone else waits one round trip to the host. That's why the lowest-ping player should host.
    Via server
    If two browsers can't connect directly (strict routers), packets go through this server instead. It works, just a little slower.
    Keep it visible
    Leave every game window open while racing. A minimised tab can fall behind.
    Names
    The name inside the game's own lobby is the game's Player 1 Name setting. Change it there to match.

    Original Game · Our Work

    Untouched: the real NFS3

    • Handling and physics: every car drives exactly like on a 1999 PC. The original code runs, recompiled, not rewritten or re-tuned.
    • Cars, tracks, AI and police: the original data from your game folder, the original opponent and Hot Pursuit logic.
    • Music and sound: the original soundtrack and effects through the game's own sound engine.
    • Menus and modes: Single Race, Hot Pursuit, Knockout, Tournament, Showcase, as you remember them.

    Added: what makes it run here

    • Static recompilation: the game's x86 code is translated to C and WebAssembly, so it runs natively in the browser with no PC emulator.
    • Voodoo2 on your GPU: the 3dfx Glide graphics path is redrawn with WebGL 2, keeping the Voodoo fog, depth and blending, and scaled up sharply.
    • Internet multiplayer: the game's LAN mode now works over the internet. Rooms with passwords and a room browser, direct browser-to-browser links, lost packets recovered in one tick, and a best-host pick so the lag goes to the fewest players.
    • Browser comfort: one-time import into private storage, mouse capture, audio, smart pacing when the tab is hidden.

    Built on the NFS3 Modern Patch by VEG (HD and widescreen support, 200+ fixes). Your game folder needs it installed.
